为什么是 Mojian

一个文件夹，就是全部

没有工作区文件，没有导入流程。打开一个文件夹，里面的普通文件就是你的项目。

纯文本，真文件

每个文件都是磁盘上的普通文件。没有数据库，没有专有格式，随时可以用别的工具打开。

标签即工作区

一个标签里并排放编辑器、图片、PDF、终端与 Git diff。拖动窗格即可重排。

终端与 SSH

内置终端打开在当前文件夹。连接远程主机时，服务端只在你使用它时运行。

图片与 PDF

截图、设计稿和文档就在项目里，不必离开窗口去预览。

Git，不离开编辑器

查看工作区改动和逐文件 diff，在标题栏切换分支。

十种配色

Petal、Mist、Meadow、Dusk、Tide、Apricot、Aurora、Dune、Paper、Plain，跟随系统明暗。

文件还在原来的地方

你的文件夹，就是项目

Mojian 不接管文件。它读你已有的文件夹，按原样保存，删掉 Mojian 也不会带走任何东西。

  • 打开任意文件夹作为项目
  • ⌘S 才写入，平时只在内存里
  • 原子写入，保存不会留下半个文件
